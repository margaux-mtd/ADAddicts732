# ADAddicts732
After the Fallout: Silence, Retaliation, or Reconciliation Between Reddit Communities?  An EPFL ADA project studying how interactions evolve after negative links.

## Data setup

Download `soc-redditHyperlinks-body.tsv` and
`soc-redditHyperlinks-title.tsv` from:
https://snap.stanford.edu/data/soc-RedditHyperlinks.html

Place both files in `data/raw/` in your local project folder.
Raw data files are excluded from Git.
